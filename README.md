# Presenting Presenting Large Language Models as Companions Affects What Mental Capacities People Attribute to Them (Data & Code for Study 1)

![Teaser photo of experimental setup. Participants are assigned to one of four conditions where they watch videos portraying LLMs as machines, tools, or companions, or watch no video. Then all participants take the same mental capacity attribution survey](./teaser.png)

## Abstract

How does messaging about about large language models (LLMs) in public discourse influence the way people think about and interact with these models? To answer this question, we randomly assigned participants in our first study (N=470) to watch a short informational video presenting LLMs as either machines, tools, or companions—or to watch no video. We then assessed how strongly they believed LLMs to possess various mental capacities, such as the ability have intentions or remember things. We found that participants who watched the companion video reported believing that LLMs more fully possessed these capacities than did participants in other groups. In a second study (N=604), we replicated these findings and found nuanced effects on how these videos impact how people rely on LLM-generated responses when seeking out factual information. Together, these studies highlight the impact of messaging about AI—beyond technical advances in AI—to generate broad societal impact.

This study was [pre-registered](https://aspredicted.org/vgdm-gjrm.pdf) with AsPredicted

## Reproducing Analyses

### Directory Structure

```
├── code/
|   ├── src/ # Python and R files to conduct analysis
|   ├── visualization_notebooks/ # Jupyter notebooks for creating graphs for papers
|   ├── 1_data_processing.ipynb # First analysis notebook that performs exclusions, reformats data, and collects demographics
|   ├── 2_factor_analysis.ipynb # Statistical analyses for mental capacities using categories from exploratory factor analysis loadings
|   ├── 3_additional_analyses.ipynb # Statistical analyses attitudes, correlations, IRR/IIR, and free responses
|   └── 4_figures.ipynb # Notebooks to make figures
├── data/
|   ├──ratings.csv # Processed ratings for all 40 mental capacity items post-exclusions
|   ├── raw/ # Raw data from Qualtrics, separated into baseline and experimental groups
|   └── files/ # Supplementary files to help with data processing
├── analysis/ # Analysis output files (not available on Github)
```

A copy of the processed rating data can be found in `data/ratings.csv` for convenience. This is identical to the `ratings.csv` file generated by the analysis code.

If you run the analysis notebooks, the outputs will save in a new directory called `analysis`.

### Prerequisites

Install [Conda](https://docs.conda.io/projects/conda/en/latest/user-guide/install/index.html) if you haven't already

### Create Conda Environment

1. Create a conda environment:
```bash
conda create -n presenting-llms python=3.9 -y
```

2. Activate the environment:
```bash
conda activate presenting-llms
```

### Install R Packages
With the conda environment activated, install `R` and necessary packages in the conda environment with

```bash
conda install -c conda-forge r-base=4.3.1 r-lme4 r-lmerTest r-emmeans r-ggplot2 r-dplyr r-tidyr r-stringr r-psych r-car r-mumin r-simr
```

Note: if there are other packages you would like to install, you can do so using the command `conda install -c conda-forge <package-name>` ensuring that the `r-` prepends each package name.

If you have issues installing `simr`, it might be because you are using MacOS or from using MiniConda instead of Anaconda. Still need to debug the root of the issue, but try to use Anaconda on Linux if possible.

### Install Python Dependencies

Install the required Python packages:
```bash
pip install -r requirements.txt
```

Note: if you have issues downloading the package `rpy2`, remove it from the `requirements.txt` file, run `pip install -r requirements.txt`, then manually install `rpy2` with the bash command `pip install "rpy2==3.5.12"`.

### Running Analysis Code

The main analyses can be found in `code`, split up into 4 Jupyter notebooks. `1_data_processing.ipynb` handles exclusions, data pre-processing, etc; `2_factor_analysis.ipynb` conducts exploratory factor analysis; `3_additional_analyses.ipynb` performs correlational analyses and analyzes attitudes; `4_figures.ipynb` makes the figures for the paper (along with additional visualizations).

Primary reported analyses in Sec 3.2 can be found in `analysis_copy/mental_capacities/factor_analysis/results/R/results` for mental capacities and `analysis_copy/attitudes/R/results` for attitudes

It is not guaranteed that running the notebooks out of order is functional.

#### Notes for Attitudes

Below is the mapping for attitudes shorthand variables to the reported names in the paper:
* `confidence`: confidence in attributions of mental capacities
* `feeling`: overall feelings towards LLMs
* `humanness`: attributions of human-likeness to LLMs
* `se_how`: confidence in their own ability to program LLMs, if given necessary training (se stands for self-efficacy)
* `se_use`: confidence in their own ability to use LLMs effectively
* `trust`: trust in the outputs of LLMs
